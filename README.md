# LinkedIn Updates & Contracting OS

Documentation and tracking system for LinkedIn profile updates, strategic positioning, and contracting playbooks for **Rifat Erdem Sahin** ([LinkedIn Profile](https://www.linkedin.com/in/rifaterdemsahin/)).

## 🚀 Quick Start & Local Preview

Run the local web dashboard on port **30083** (or any port 30k+):

```bash
python3 -m http.server 30083
```

Open in Google Chrome:
```bash
open -a "Google Chrome" http://localhost:30083
```

## 📂 Repository Contents

- **`index.html`**: Interactive web dashboard featuring one-click copy buttons for headlines, about sections, featured skills, announcement posts, and the 4 pillars of contracting.
- **`profiles.html`**: Exported Profile Scoring Engine evaluating candidates and CV variants across 5 weighted contracting dimensions.
- **`todos.html`**: Interactive task management board with category filters, priority tags, and browser localStorage persistence.
- **`skills-gaps.html`**: Comprehensive 2026 AI Skills Gap Analysis across 6 critical domains with bridge actions, recommended frameworks, and a 30-60-90 day roadmap.
- **`nav.js` & `nav.css`**: Shared navigation bar and live global search system (`Ctrl+K` or `/`).
- **`exports/`**: Directory storing exported CV and LinkedIn profile PDFs.
