Pillar 1 • Test-Time Search

1. STaR & GRPO Reinforcement Loops

Self-Taught Reasoner (STaR) and Group Relative Policy Optimization (GRPO) represent the shift toward models discovering their own reasoning strategies. Instead of mimicking human chains, the model explores multiple rationale paths, rewards correct outcomes, and fine-tunes itself on verified successes.

Core Loop: STaR Rationalization Engine 
# Self-Taught Reasoner (STaR) Minimal Sampling Loop
def star_self_learn_step(model, question, ground_truth, n_samples=8):
    # 1. Sample multiple reasoning rationales
    candidates = model.generate_rationales(question, n=n_samples)
    
    # 2. Filter via outcome/process verifiers
    verified = [c for c in candidates if verify_answer(c.answer, ground_truth)]
    
    # 3. Rationalization for failed instances (hinted self-correction)
    if not verified:
        hint = f"Hint: The correct final answer is {ground_truth}"
        verified = model.generate_rationale_with_hint(question, hint)
        
    # 4. Commit winning reasoning traces to fine-tuning dataset
    replay_buffer.add(question, verified)
    return model.step_dpo_or_grpo(replay_buffer)
Pillar 2 • Episodic Self-Correction

2. Reflexion: Verbal Reinforcement Learning

Pioneered by Shinn et al. Rather than updating neural weights with slow gradient backpropagation, the agent translates runtime environment errors (unit test fails, API exceptions, hallucinated schemas) into natural language self-critiques stored in persistent episodic memory.

Reflexion Episodic Memory Loop 
# Reflexion: Turning Execution Failures into Memory
class ReflexionAgent:
    def __init__(self):
        self.memory = EpisodicBuffer()

    def execute_with_reflection(self, task, max_trials=3):
        for trial in range(max_trials):
            context = self.memory.retrieve_relevant_critiques(task)
            trajectory = self.actor.run(task, past_mistakes=context)
            evaluation = self.evaluator.test(trajectory)
            
            if evaluation.passed:
                return trajectory.solution
            
            # Autonomous Self-Reflection
            critique = self.self_critique(trajectory, evaluation.error)
            self.memory.append(task=task, critique=critique)
        raise SystemStallError("Max self-correction trials reached")

3. Autonomous Tool & Skill Synthesis (Voyager)
